# PROG5121 - Programming Project (POE) Part 3

## 1. Project Overview

This repository contains Part 3 of the PROG5121 Programming Project of Expertise (POE). The project is developed using Java in the NetBeans Integrated Development Environment (IDE).

The purpose of this project is to demonstrate practical programming knowledge, object-oriented programming principles, data management, and the implementation of software functionality.

## 2. Project Objectives

The main objectives of this project are to:

- Apply Java programming concepts to develop a functional application.
- Demonstrate the use of arrays and data structures.
- Implement methods to manage and process stored messages.
- Apply object-oriented programming principles.
- Improve problem-solving and logical thinking skills.
- Use software testing to verify that the application works correctly.

## 3. Technologies and Tools

The following technologies and tools are used:

- **Programming Language:** Java
- **IDE:** Apache NetBeans
- **Version Control:** Git
- **Source Code Repository:** GitHub
- **Testing Framework:** JUnit

## 4. Main Project Features

The Part 3 implementation focuses on extending the QuickChat application with stored-message management functionality.

Key areas include:

- Managing message information using arrays.
- Storing and retrieving message data.
- Searching and processing stored messages.
- Implementing the required Stored Messages functions.
- Displaying relevant message information.
- Testing application functionality.

## 5. Programming Concepts Applied

The project demonstrates the use of:

- Classes and objects.
- Methods and constructors.
- Arrays.
- Loops and conditional statements.
- Encapsulation.
- Data processing.
- Unit testing.

## 6. Development Environment

The application is developed in Java using NetBeans. GitHub is used to maintain the source code and track project changes through commits.

## 7. Testing

JUnit is used to test the application's methods and verify that the implemented functionality produces the expected results.

Testing helps identify errors and improve the reliability of the application.

## 8. Repository Structure

The repository contains the Java source code, test files and supporting project documentation required for Part 3.
